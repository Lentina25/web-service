# Приложение для подбора косметики и парфюмерии

Данный проект разработан в рамках лабораторного практикума по контейнеризации многокомпонентных приложений.

## Архитектура проекта
Проект состоит из 4 контейнеров, разворачиваемых через Docker Compose:
1. **Frontend**: Nginx сервер, отдающий статический HTML/JS интерфейс (Порт 3000).
2. **Backend**: API на FastAPI (Python), связывающий сервисы (Порт 8000).
3. **Database**: СУБД PostgreSQL, хранящая историю предпочтений клиентов.
4. **Web-service**: Микросервис-эмулятор подбора косметических средств по типу кожи и ароматам.

## Инструкция по локальному запуску

```bash
# 1. Сборка и запуск всех контейнеров в фоновом режиме
docker compose up --build -d

# 2. Проверка статуса контейнеров
docker compose ps
```

После успешного запуска проект доступен в браузере по адресу: `http://localhost:3000`
